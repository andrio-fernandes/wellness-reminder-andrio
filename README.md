# 💊 Wellness Reminder App

## 🌍 SDG Alignment

This project is based on **Good Health and Well-being (SDG 3)**, which focuses on ensuring healthy lives and promoting well-being for all.

---

## 📌 Problem Statement

Many individuals forget to take their medicines on time due to busy schedules, lack of tracking systems, or simple forgetfulness. This problem is especially critical for:

* Elderly individuals
* Patients with chronic illnesses
* People managing multiple medications

Missing doses can lead to poor treatment outcomes, worsening health conditions, and increased medical costs.

---

## 💡 Solution

The **Wellness Reminder App** is a full-stack web application that helps users manage their medication schedules effectively.

It allows users to:

* Add medicines with dosage and timing
* Receive reminders via browser notifications
* Get backup email alerts
* Track whether doses are taken or missed
* View adherence statistics through a dashboard

## ✨ Features

### 🔐 User Authentication

Secure signup and login system to manage personal medication data.

### 💊 Medicine Management

Users can add, edit, and delete medicines with custom schedules and dosage details.

### 🔔 Smart Reminder System

Real-time browser notifications remind users to take medicines, with options to:

* Mark as **Taken**
* **Snooze** reminders

### 📧 Email Backup Reminders

If a notification is missed, the system sends an email reminder.

### 📊 Adherence Dashboard

Visual representation of medication consistency using charts and statistics.

### 📜 Dose Tracking

Tracks all doses as **taken**, **missed**, or **pending**.

### Frontend

* Tailwind CSS – Styling and responsive design

### Backend & Services

* Lovable AI – Backend, authentication, and deployment
* PostgreSQL – Data storage and management

### Other Tools

* ChatGPT – Prompt design, planning, and structuring
* Browser Notifications API – Real-time alerts
* Email services via Lovable

---

## ⚙️ How It Works

1. User signs up and logs in
2. Adds medicines with time and dosage
3. The system schedules reminders
4. Notifications are triggered at the correct time
5. User marks dose as taken or missed
6. Data is stored and displayed in the dashboard
